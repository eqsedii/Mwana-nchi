MWANANCHI SUPPLIES LIMITED - website
1. Upload ALL files/folders in this zip to your repo root (index.html must be at the root).
2. Open config.js and set your real WhatsApp number (format 2547XXXXXXXX), phone, email, address.
3. Also search contact.html and index.html for "254700000000" and replace it with your number.
4. Prices live in products.js (p = price in KSh, null = "Request quote").
5. Customer names for pop-ups live in names.js.
Hosting: works on GitHub Pages / Netlify / Vercel (static site, no server needed).
